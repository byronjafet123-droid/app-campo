# App de campo · Ganadería

App para anotar en el teléfono el trabajo de las fincas: fincas, hatos, animales por arete, aplicaciones sanitarias, gastos, ventas y traslados.

- Los datos se guardan **solo en el teléfono**. Este repositorio tiene únicamente el programa.
- Se instala en Android desde Chrome: menú ⋮ → "Agregar a la pantalla principal" / "Instalar app".
